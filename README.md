# OpenLint legacy Spectral AsyncAPI ruleset

Compatibility package for the original `spectral:asyncapi` ruleset. It preserves
the full legacy AsyncAPI ruleset for existing configurations and JavaScript API
consumers.

Install the package and extend it directly:

```sh
npm install --save-dev @openlint/ruleset-spectral-asyncapi
```

```yaml
extends: "spectral:asyncapi"
```
